# SAZ LogicTranway

## Описание проекта
Это веб-приложение для логистики транспортных путей, разработанное как прототип. Оно предназначено для автоматизации выбора машин для перевозки грузов на основе параметров (вес, размеры, количество) и статуса транспортных средств. Приложение интегрируется с Yandex Maps для расчёта оптимальных путей. В будущем планируется адаптация под "Задачи САЗ" как микросервис, с добавлением базы данных для машин и грузов, а также умного алгоритма подбора.

На данный момент это чистый фронтенд-прототип без бэкенда:
- Форма для ввода параметров груза (название, вес, длина, ширина, количество, точки отправления/назначения).
- Кнопка "Подобрать машину" (симулирует подбор с alert и строит маршрут на карте).
- Интеграция Yandex Maps для отображения маршрутов.

## Запуск
  ```
  npm run start
  ```
- Откройте в браузере: `http://localhost:8080/src/index.html` (или порт, указанный в скрипте).
